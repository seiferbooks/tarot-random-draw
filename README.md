# Animated Divination Draw

A static divination site with animated shuffle, deal, and reveal sequences.

- Secure random draw in the browser
- 78-card Rider–Waite–Smith tarot deck
- Original 44-card oracle deck with generated artwork
- Traditional 36-card Lenormand deck with generated artwork
- Traditional jiaobei casting with generated artwork
- Optional repeated cards and independent upright/reversed orientations where applicable
- Short shuffle, deal, and card-reveal animation with a stable card layout
- 1909 Rider–Waite–Smith public-domain artwork
- Mobile-friendly numeric input, result tabs, and multiline copy support

The repository contains all required assets. GitHub Pages packages `animated/index.html`, three optimized generated WebP assets, the lightweight version, and all 78 tarot images without depending on another hosted site.

## Available versions

- [Illustrated version](https://seiferbooks.github.io/tarot-random-draw/)
- [Lightweight version](https://seiferbooks.github.io/tarot-random-draw/simple/) — no card images or shuffle/reveal animation

The animated source is stored at `animated/index.html`. The lightweight source is stored at `simple/index.html`.
